# Truth Trail

TruthTrail AI is a multi-agent fact-checking platform that investigates online claims using independent AI agents. It gathers supporting and opposing evidence, evaluates source quality, detects missing context, and presents an explainable verdict with an interactive evidence trail. Instead of asking users to blindly trust AI, TruthTrail makes the reasoning, evidence, uncertainty, and agent disagreements transparent.
